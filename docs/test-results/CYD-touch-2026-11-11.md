# CYD touch input acceptance — 2026-11-11

- **Board:** ESP32-2432S028 CYD, ILI9341 display, XPT2046 resistive touch
- **Profile:** `esp32_2432s028_spiffs`
- **BASIC demo:** [`examples/touch/touch-demo.bas`](../../examples/touch/touch-demo.bas)

## Coordinate correction

Corner samples from the initial mapping were:

| Screen point | Reported X | Reported Y |
| --- | ---: | ---: |
| Upper left | 3 | 235 |
| Upper right | 319 | 233 |
| Lower left | 2 | 2 |
| Lower right | 319 | 4 |

X already followed the horizontal screen axis. Y followed the vertical axis in
reverse. The CYD adapter now preserves X and flips Y before applying display
rotation. The transform uses nominal raw bounds of 250–3850; a runtime
calibration wizard is not implemented.

## Window hit testing

The first demo window was 320×176 on a 320×240 screen. Touches outside that
window were correctly ignored by the window manager. The demo now uses a
320×240 window so taps in all four screen corners have a hit target. The user
confirmed that touch input works after these corrections.

Touch coordinates are reported relative to the captured BASIC window. Physical
touch behavior at rotations other than 0° has not yet been checked.
