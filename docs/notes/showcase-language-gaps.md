# Language and runtime gaps found while building The Grand Tour

Running log. Each entry: gap, workaround, cost, suggested change, priority (H/M/L).

| # | Gap | Workaround | Cost | Suggested change | Prio |
| --- | --- | --- | --- | --- | --- |
| 1 | `PRIORITY`, `SUSPEND`, `RESUME`, `SLICE` are shell-only (not BASIC statements) | Scene 4 shows task speed differences with different `PAUSE` pacing instead of weights | Cannot demonstrate weighted scheduling from a program; some honesty lines in the caption | Allow `PRIORITY id,w` / `SUSPEND` / `RESUME` as statements (supervisor tasks only) | M |
| 2 | A worker's default window is a half-width slot (CYD 160x240 at x=160), not the screen; `GWIDTH()` before `WINDOW` is not the screen size | Parse `WxH` out of `SYSINFO$(3)` in the layout library | About 10 lines of string parsing in every task that includes the library (duplicated code per task) | `DISPLAYW()/DISPLAYH()` (and usable-area) functions, or numeric `SYSINFO(selector)` | H |
| 3 | `CAPABILITY("audio")` is `-1` (unknown) on CYD/Tenstar; `SYSINFO$(6)` lists no audio; `SYSINFO$(5)` shows no `sdc` | Probe by attempting `MUSIC PLAY`/`OPEN` under `TRAP` and checking `ERR` | Extra TRAP wrappers and a failure path per scene | Make capability queries truthful (`audio`, `sdc`, `touch`, `ps2`) and list them in features | H |
| 4 | Serial arrow keys are not decoded by `INKEY` (`ESC [ A` arrives as 27, 91, 65) | Use letter keys (`N`, `P`, `M`, `Q`, space) | None for the tour; serial users cannot use arrows | Decode ANSI cursor sequences into `KKeyUp` etc. in the serial input path | L |
| 5 | Workers take no arguments (`TASK path` only) | Derive everything from run-time queries; the director communicates nothing to scenes | Every scene recomputes layout | `TASK path, arg$` plus `ARG$()` | M |
| 6 | `TASKVIEW` (and `DEBUGBAR`, `WINDOWMODE`, `MODE`) work only in the supervisor session, i.e. the foreground `RUN`; a director started with `TASK` fails with "TASKVIEW is supervisor-only" | Run the showcase foreground with `RUN`; no helper task can place tiles | The tour cannot be launched from another program or from `startup.bas` via `TASK`; test mode needs `STOP` to leave scenes on screen | Allow a task to be granted supervisor rights (e.g. `TASK path, KTaskSupervisor`), or let a task place only its own children | M |
| 7 | Procedures cannot see global arrays: `g$(0) = ...` inside a `DEFine PROCedure` parses as a procedure call ("procedure calls use command syntax without parentheses") | Packed the title glyph rows into one string and index with `MID$` | About 8 lines, plus a misleading error message | Allow reading and writing global arrays from procedures, or improve the error to name the undeclared array | M |
| 8 | `CONST` after `INCLUDE` is rejected ("CONST declarations must precede definitions") | Dropped the constant | Each task file must order CONST before INCLUDE | Allow CONST after INCLUDE of definitions-only files | L |
| 9 | One-line `IF ... THEN stmt ELSE stmt` is not supported | Block IF/ELSE/END IF | Extra lines | Accept inline ELSE | L |
| 10 | `RECT x,y,w,h,1` (optional fifth argument) inside a procedure, called in a loop, triggered a `TG1WDT_SYS_RESET` watchdog reset on the CYD; the same loop with four arguments is fine | Use the four-argument form | One board reset to diagnose, about 30 minutes | **Fixed**: root cause was not the watchdog but a memory overrun. A filled `RECT` lying entirely outside its (tile-sized) window computed a negative span that wrapped to a huge `size_t` in `plotSpan`, corrupting the heap; the reset appeared when a fourth task started. Now clipped away | Done |
| 11 | `@SCREEN` capture is not answered while a foreground program is running, so a hands-free tour cannot be photographed | `holdScene` test mode ends the run with `STOP` so the REPL prompt returns while tiles keep running | A test-only hook in `showcase.bas` | Handle `@SCREEN` in the serial monitor path even when a program owns the console | M |
| 12 | `step` is a reserved word, so `FOR step = ...` fails with "expected numeric FOR variable" | Renamed the variable | One failed device run | Name the reserved word in the error message | L |
| 13 | `OPTION` must precede all definitions, but `INCLUDE` must also precede module code and `OPTION KOptMathSingle` needs a `CONST`; a shared body (`gt-mathbody.bas`) cannot be reused by a single-precision twin after `INCLUDE "ql32.inc"` | A one-line-pair `gt-optsingle.bas` (CONST + OPTION) included first | Extra file; `ql32.inc` cannot be used | Allow `OPTION` after definitions-only includes, or let `INCLUDE` carry `OPTION` | M |
| 14 | No `SQRT`/`SQR`, `LN`, `EXP`, `ATN` (only `SIN`, `COS`, `INT`, `RND`); the compile error is the generic "undefined procedure or function" | Used `2 ^ 0.5` | Obscure error, two device round trips | Add the standard numeric functions; they are expected by BASIC users | H |
| 15 | `RECT x,y,w,h` without the fifth argument is an outline; entry 10's watchdog reset was with the filled form (`,1`) | One-pixel-wide columns drawn with `LINE` instead of `RECT` | A bug-hunt on a "green screen" | Document; entry 10 is fixed (off-canvas fill overrun) | M |
| 16 | `TEXT` in the director is clipped near 160 px (about 31 characters of font 1) whenever tiles exist, although the same long string draws in full from the REPL | Captions kept to 30 characters | Terse captions | Investigate clipping of `TEXT` after `TASKVIEW`/task start | M |
| 17 | Killing task canvases leaves the heap fragmented: after scenes 1-3 free is 136K again but the largest block is 28-30K, so a later 28.8K canvas fails ("have 75464 free, 28660 largest") | Run scenes from a clean reset in tests; heap order (large canvases first) in the tour | A real risk for the sequential tour on the CYD | Compacting allocator or fixed canvas pool; tracked for Phase 6 | H |
| 18 | After `STOP` in a foreground program, task windows are effectively frozen (only a few frames ran), so screenshot mode must `PAUSE` before `STOP` | `holdScene` now waits 6 s then stops | Test hook complexity | Document `STOP` semantics for running tasks | L |
| 19 | GCOPY-based scrolling costs about 120 ms per 3-layer frame on the CYD (320x180) | Single-pixel-step scrolling, 4/2/1 px per layer | About 8 fps parallax on the CYD | Accelerate `GCOPY` (DMA / fewer present passes) | M |
